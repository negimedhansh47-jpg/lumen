## Decisions that are not obvious from the code
- Concept cards are static reviewed text. "Explain this better" (added 2026-11-23 at the human's request, not in SPEC) asks the model to re-teach the card; it takes no user text, so results are cached in D1 per concept and level.
- "My project" (added 2026-11-23 at the human's request, not in SPEC) is localStorage only (`public/js/project-store.js`, shape-checked on load and import). It tracks a repo + last-seen sha, a saved kickoff plan with a checklist, and opened concepts. Export/import JSON moves it between devices. No server storage, so no auth needed.
- Design v4 (2026-11-23, palette picked by the human): white/sky-white + ink black #00171F, deep space blue #003459 for the dark band, ONE accent cerulean #007EA7 used only for things you click to move forward (primary buttons, links, concept chips, active states). Fresh Sky #00A7E1 is decoration only (too light for text). Red/green soft panels only for before/after. Fonts: Instrument Serif display, Space Grotesk headings, Inter Tight body, JetBrains Mono labels. Motion respects prefers-reduced-motion.
- Clarity rules: one name per tool everywhere (Plan an idea /kickoff, Review a chat /chat, Explain a repo /repo, My project /project). Home leads with "What do you have right now?" (idea / chat / repo). Every tool page shows 1-2-3 steps, a primary button, an "or try an example" button, scrolls to results, and ends with a "What next?" card. Level toggle reads "Explain for: Beginners / Some experience".
- Ask about your project (2026-11-23, human request, not in SPEC): POST /api/project/ask. Repo facts come from the cached overview in D1 (no GitHub calls; 409 if the map was never opened), plan comes from the browser. Question and history are user content (fenced, never stored). Cited files are filtered to ones in the map. Chat history is in memory only. UI: public/js/ask.js on My project and Explain a repo (live repos only).
- Tool pages use guide() in shell.js: step pills light up, main button stays off with a reason until there is input.
- Auth: deliberately none. Nothing user-specific is stored, and a login wall would slow judges down. Revisit only for private repos (GitHub OAuth).
- Model: NVIDIA NIM `nvidia/nemotron-3.5-super-vl-120b-a12b`, sent with `enable_thinking:false`. Fallback Workers AI Llama 3.3 70B. Chain: NIM, NIM retry, Workers AI, friendly error. Test results: `AI_USAGE.md`.
- Trust model: LLM output is untrusted. Evidence paths are checked against the repo tree, chat excerpts must be verbatim substrings, duplicate excerpts are dropped, unknown concept ids become null.
- `/api/repo/commits` returns no `filesChanged` (would cost 15+ GitHub subrequests). It takes `?path=` instead, which powers the drawer's commit list.
- Free-plan limits drive design: 50 subrequests per request, 10 ms CPU, 100k requests/day. Rate limit: 30 LLM calls per IP per hour, global daily cap 1500.
- Examples (`public/demo/*.json`) are generated by `scripts/make-demo.mjs` against a local `wrangler dev` on :8799. Stop any preview server on 8799 first.
- Design: cream paper, serif headlines, one accent (#E4572E decorative, #C4411D for text). Grain overlay and card spotlight are the only decoration. Design references looked at: 21st.dev (dark, React, shader-heavy; wrong mood, only the pointer-spotlight idea was borrowed).
