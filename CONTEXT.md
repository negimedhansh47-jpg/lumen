## Decisions that are not obvious from the code
- Model: NVIDIA NIM `nvidia/nemotron-3.5-super-vl-120b-a12b`, sent with `enable_thinking:false`. Fallback Workers AI Llama 3.3 70B. Chain: NIM, NIM retry, Workers AI, friendly error. Test results: `AI_USAGE.md`.
- Trust model: LLM output is untrusted. Evidence paths are checked against the repo tree, chat excerpts must be verbatim substrings, duplicate excerpts are dropped, unknown concept ids become null.
- `/api/repo/commits` returns no `filesChanged` (would cost 15+ GitHub subrequests). It takes `?path=` instead, which powers the drawer's commit list.
- Free-plan limits drive design: 50 subrequests per request, 10 ms CPU, 100k requests/day. Rate limit: 30 LLM calls per IP per hour, global daily cap 1500.
- Examples (`public/demo/*.json`) are generated by `scripts/make-demo.mjs` against a local `wrangler dev` on :8799. Stop any preview server on 8799 first.
- Design: cream paper, serif headlines, one accent (#E4572E decorative, #C4411D for text). Grain overlay and card spotlight are the only decoration. Design references looked at: 21st.dev (dark, React, shader-heavy; wrong mood, only the pointer-spotlight idea was borrowed).

## Windows gotchas
- Never `Get-Content | Set-Content` on source files: it corrupts UTF-8. Use the Edit/Write tools.
- Editing `public/` restarts `wrangler dev`.
